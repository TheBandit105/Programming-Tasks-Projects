# FieldAssist

FieldAssist is a personal Python project designed to improve
Windows diagnostics for IT Field Support.

## Current Features

- System Information
- Disk Information
- Memory Information

## Planned Features

- Network Information
- Battery Information
- BitLocker Status
- Event Log Analysis
- Device Health Checks

## Learning Goals

- Python
- Project Structure
- Modular Programming
- Windows Administration
- PowerShell Integration
- Git and Version Control
- Third-Party Python Packages
- Error Handling
- Logging
- Unit Testing
- REST APIs
- FastAPI
- Vue.js
